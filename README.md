# 📱 Indian Kids Screen Time Analysis

A data analytics project completed as part of the **Infosys Springboard Virtual Internship**, focusing on analyzing screen time patterns among Indian children using Python and Power BI.

---

# 📌 Project Overview

This project analyzes children's screen usage habits across different age groups, device categories, and demographic segments. The objective is to identify usage patterns, potential health risks, and meaningful insights through data visualization.

---

# 🎯 Objectives

- Analyze average daily screen time.
- Compare screen usage across age groups.
- Identify the most frequently used devices.
- Study demographic trends.
- Build an interactive Power BI dashboard.
- Generate actionable insights from the data.

- Health Risk Distribution

---

# 🔍 Key Insights

- Screen time varies significantly across age groups.
- Mobile devices are the most commonly used.
- Older children generally spend more time on screens.
- Urban and rural usage patterns show noticeable differences.
- Interactive visuals enable quick exploration of trends.
